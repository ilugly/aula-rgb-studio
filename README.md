<h1 align="center">AULA RGB Studio</h1>

<p align="center">Неофициальная программа для подсветки клавиатуры <b>AULA F75 / F75 Pro</b>:<br>
многоцветные анимации, которых нет в родном софте, и редактор режимов, записанных в саму клавиатуру.</p>

---

## Что умеет

- **Живые анимации любых цветов.** 16 готовых сцен (северное сияние, сакура под дождём, костёр, звёздная ночь, лавовая лампа…), 19 эффектов, 16 цветовых тем и свои цвета: от 2 до 6 на выбор.
- **Эффекты от набора текста.** Кольца расходятся от нажатых клавиш, клавиши тлеют после нажатия.
- **Превью = клавиатура.** Большая клавиатура на экране показывает ровно то, что сейчас светится на твоей.
- **Память клавиатуры.** Можно поменять цвет, яркость и скорость встроенных режимов, записать свою картинку на клавиши. Это работает и без компьютера. Перед первой записью программа сама делает резервную копию.
- **Живёт в трее.** Иконка у часов: открыть, включить/выключить анимацию, автозапуск с Windows, выход. Анимация идёт и с закрытым браузером.

## Установка

1. Скачай **`AULA-RGB-Studio.exe`** со страницы [Releases](../../releases/latest).
2. Вставь 2.4G-донгл, а переключатель на задней стороне клавиатуры поставь на **2.4G**.
3. Запусти `.exe`. У часов появится иконка, а в браузере откроется страница управления.

> Windows может показать предупреждение «Windows защитила ваш компьютер», потому что у программы нет платной цифровой подписи. Нажми **«Подробнее» → «Выполнить в любом случае»**. Некоторые антивирусы ругаются на любые программы, собранные PyInstaller. Если не доверяешь `.exe`, запусти из исходников (см. ниже).

Чтобы программа включалась сама, отметь в трее **«Запускать вместе с Windows»** или включи это в разделе «Настройки» на странице.

## Что поддерживается

| | |
|---|---|
| Клавиатура | AULA F75 / F75 Pro |
| Подключение | только 2.4G-донгл (`3554:FA09`). Провод и Bluetooth не поддерживаются |
| Система | Windows 10 / 11 |

Если клавиатура не отвечает, значит она уснула: нажми любую клавишу.

## Запуск из исходников

Нужен Python 3.10+.

```bat
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\pythonw app.py
```

Собрать `.exe` самому: `build.bat`, результат появится в `dist\AULA-RGB-Studio.exe`.

## Как это устроено

- `app.py` — иконка в трее, запускает всё остальное.
- `server.py` — локальный сервер на `127.0.0.1:8777`: отдаёт страницу, читает и пишет настройки клавиатуры, крутит анимацию.
- `effects.py` — все эффекты и упаковка кадра в формат клавиатуры (не больше 11 цветов и 126 байт на кадр, пауза 5 мс между пакетами).
- `aula_hid.py` — доступ к донглу через Windows HID без сторонних библиотек.
- `web/index.html` — интерфейс.
- `tools/` — скрипты для диагностики протокола.

Настройки хранятся в `%APPDATA%\AULA RGB Studio\settings.json`.

## Важно

Это неофициальный проект, он никак не связан с AULA. Программа пишет в память клавиатуры только те же настройки, что и родной софт, а перед первой записью сохраняет копию. Но пользуешься ты ей на свой страх и риск.
